# 常见问题

## 安装失败或文件被占用

先退出 Sunshine 控制面板，再解压并运行 `安装集成版.bat`，接受管理员授权。查看解压目录中的 `installation-error.txt`；它是本机诊断文件，不要直接公开上传含个人路径的全文。

## 找不到 Sunshine 或提示版本不兼容

当前安装器只支持 `C:\Program Files\Sunshine` 下的 GUI 0.5.9 系列，不能直接覆盖任意版本。请先核对安装位置、版本及基地版核心兼容性。

## 虚拟屏开关显示状态未知

先启动 Sunshine 服务，再点开关旁的刷新。开关依赖核心的本地 `api/tray` VDD 接口及已安装的虚拟显示驱动。驱动缺失或核心不支持时，安装面板补丁不能补齐这些组件。

## 开启虚拟屏后又自动消失

开启后需要在 Keep Virtual Display? 弹窗中点“是”；20 秒未确认会自动撤销。关闭和切换期间会短暂禁用开关，待冷却结束再操作。

## 传输端口被其他程序占用

检查是否另有旧中继仍在运行，先关闭自己的旧中继窗口。不要随意停止不认识的程序。集成脚本只会接管符合其生产双隧道参数的中继，遇到无法确认归属的端口占用会退出并显示原因。

## HDC_MISSING / PYTHON_MISSING

分别安装华为官方 HDC 工具和 Python 3，并确认命令可用。HDC 也可放到 `C:\Program Files\Sunshine\tools\harmony-usb\hdc.exe`。本补丁不附带这些工具。

## USB_NO_DEVICE / USB_DEVICE_OFFLINE

检查数据线是否支持数据传输，平板是否已开启 USB 调试并允许这台电脑连接。多台设备同时接入时，需要在面板选择对应设备。

## BRIDGE_MISSING

平板还未安装 USB 隧道伴侣。需先按照 `pad/README.md` 自行签名构建并安装，再启用 USB 模式；只安装电脑补丁不够。

## 配对能成功，但串流黑屏或之后无法重连

先检查平板桥是否仍在运行、是否被系统冻结。当前建议保持桥以分屏或悬浮窗可见。重新打开桥并重新连接 Moonlight；若持续失败，再检查 Sunshine 和中继的当前日志。

Moonlight 的 error 0 / error -1 以及“网络连接拦截”提示都不能单独确定故障点，需要结合核心、映射和桥状态排查。

## 回到网络模式后找不到旧主机

网络模式使用电脑的实际局域网地址，USB 模式才使用平板本机 `127.0.0.2`。模式切换会重启 Sunshine，端口由集成脚本恢复；不要同时手工改配置。

## 恢复原版面板

运行补丁解压目录中的 `恢复原版面板.bat`。原面板和每次更新前的备份保存在 Sunshine 的 `tools\harmony-usb-backups` 下。面板恢复与网络模式切换是不同操作；需要恢复网络传输时应先在设备中心切回网络模式。
