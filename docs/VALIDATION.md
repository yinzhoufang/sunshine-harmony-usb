# 验证范围

版本：GUI 0.5.9+usb.2，原生桥媒体调度 v3。以下是单台电脑与平板上的结果，尚未验证通用部署。

## 虚拟显示器

- 前端测试 134 / 134，通过；新增 Rust 后端测试 4 / 4，通过。
- 前端生产构建及 Windows Rust release 构建成功。
- 本机正式界面“虚拟显示器”页面顶部存在开关，开启 / 关闭由真实 GUI 点击触发。
- 创建后核心报告 `active=true`；关闭后报告 `active=false`，操作 `vdd_destroy` 为 `succeeded`，最终 `cooldown=false`。
- 未在 20 秒内确认时，虚拟屏自动关闭并进入短暂冷却，此路径已验证。
- 本次自动验收使用本地核心接口确认“保留”。原生弹窗自动点击未完成，因此不声称整个确认弹窗交互已由自动化覆盖。
- 功能安装及测试前后，Sunshine 核心、主配置与传输模式状态文件的哈希保持一致。
- 构建产物 EXE SHA-256：`96eaf0d53a50b5274141cb4cbe916ce66163de948334afaf1283ce01ed8a485f`。

## 40 Mbps 双隧道回显

测试时长 60 秒，按 60 fps 突发组织媒体负载。视频上下行各约 40 Mbps，此负载不同于真实游戏的上行流量。

| 指标 | 结果 |
|---|---:|
| 视频返回 | 214,285 / 214,285 包 |
| 控制返回 | 7,200 / 7,200 包 |
| 音频返回 | 6,000 / 6,000 包 |
| 桥 dropped 新增 | 0 |
| 双隧道失联采样 | 0 |
| 控制 RTT p50 | 6.113 ms |
| 控制 RTT p95 | 16.264 ms |
| 控制 RTT p99 | 23.695 ms |
| 视频 RTT p99 | 26.386 ms |

这些数值是桥接传输的回显耗时，未包括输入采集、游戏渲染、编码、解码和屏幕显示，不能当作完整操作延迟。

## 不在本次验证范围内

- 更多 Windows 电脑、不同 Sunshine 核心版本及其他 HarmonyOS 设备。
- 长时间纯后台运行、两台客户端独立桌面、多显示器自动回收的所有边界情况。
- 平板通用发行签名与应用市场分发。
